## 踩坑记录（重要）

1. **未佩戴自动休眠会中断传输**——头显锁屏后追踪器/手柄连接会断开，正在进行的刷写被打断。
   解决：`setprop pvr.factorytest.never.sleep 1`（临时，重启自恢复），或保持头显活跃。
2. 追踪器刷写后会**离线重启**（1–2 分钟），回来即显示新版本——期间显示离线属正常。
3. **中断后可直接重刷**（同一命令），无副作用；首次中断的 tracker1 重刷后完全正常。
4. 刷写过程中日志可能显示 tracker reset（reset_flag），属官方 OTA 流程正常现象。
5. `tracker_test UpdateTracker <n> <bin>` 会**依次处理整个追踪器组**；整套约 3–4 分钟。
6. 固件镜像有签名校验（两代固件共用同一签名体系），非官方固件无法通过校验。
