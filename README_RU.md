# Прошивка PICO Motion Tracker: обновление и откат

> ⚠️ Неофициальный проект, только для изучения и исследований. Авторские права на прошивку принадлежат PICO; все операции вы делаете на свой риск.

Инструменты и инструкции для **обновления и отката** прошивки **PICO Motion Tracker** на PICO 4.
В основе лежит уже входящая в систему утилита `tracker_test`; **двусторонняя прошивка (и обновление, и откат) проверена на реальном устройстве**.

## ✅ Проверенные результаты (PICO 4 A8110 + 3 трекера, 2026-09)

| Направление | Результат |
|---|---|
| Обновление | ✅ TR0189 (sv1.89) → **TR0191 (sv1.91)**, все три трекера успешно |
| Откат | ✅ TR0191 → TR0189 реально работает (**можно прошить обратно**), ничто не мешает обоим направлениям |
| Время | около 3–4 минут на весь комплект; во время прошивки трекеры ненадолго отваливаются и перезагружаются (это норма) |

## Что это такое

Входящая в систему утилита `tracker_test` умеет прошивать уже сопряжённые трекеры:

```bash
tracker_test UpdateTracker <1|2|3> /path/to/Swift2.0_sv1.XX_....bin
```

Этот репозиторий содержит:

- **Проверенные образы прошивок** (`firmware/`): sv1.89 (идёт с PICO 4 из коробки) / sv1.91 (поколение PICO 4 Ultra)
- **Вспомогательные скрипты** (`tools/`): прошивка с ведением журнала, переключатель бодрствования, проверка состояния
- **Записи реальных тестов** (`docs/`)

## Использование

### Требования

- Root (Magisk) — нужен для запуска системной утилиты
- Трекер на связи (он подключается, пока включён экран шлема) и достаточно заряжен
- **Не давайте шлему уснуть, держите экран активным** — это критично: автоматический сон без надевания прерывает передачу

### Шаги

```bash
# 0. Записываем прошивку и скрипты на устройство
adb push firmware/Swift2.0_sv1.91_20250827_b191_app.bin /data/local/tmp/
adb push tools/*.sh /data/local/tmp/

# 1. Запрещаем шлему засыпать (после прошивки не забудьте выключить)
adb shell su -c "sh /data/local/tmp/keep_awake.sh on"

# 2. Прошиваем (команда проходит по всей группе трекеров, нужно несколько минут)
adb shell su -c "sh /data/local/tmp/update_tracker.sh 1 /data/local/tmp/Swift2.0_sv1.91_20250827_b191_app.bin"

# 3. Проверяем (дождавшись, пока трекеры вернутся)
adb shell su -c "sh /data/local/tmp/check.sh"

# 4. Возвращаем обычную политику сна
adb shell su -c "sh /data/local/tmp/keep_awake.sh off"
```

### Откат

Той же командой прошейте `firmware/Swift2.0_sv1.89_20241213_b189_app.bin` (проверено).

## Частые вопросы

- **Передача прервалась?** Просто повторите ту же команду — прошивка начнётся заново; в моих тестах после этого всё работало как обычно.
- **Можно ли превратить трекер в кирпич?** Образ проходит проверку подписи; прерывание стоит только повторной попытки, железо повредить нельзя.
- **После прошивки трекер пропал?** Он перезагружается и вернётся через 1–2 минуты (состояние видно в `check.sh`).
- **Откуда прошивки**: sv1.89 — копия из системы PICO 4, `/system/etc/trackerbin/`; sv1.91 извлечена из системного компонента PICO 4 Ultra.
- **Замечание**: официальный канал P4 до сих пор несёт sv1.89, а 1.91 — это поколение Ultra. Если после обновления захотите вернуться, используйте шаги отката выше.
